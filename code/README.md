# Code

## `generate_figures.py` and `dfm_figures/` — figure reproduction

Regenerates the seven data-driven figures of the paper and the two supporting figures from the CSV
files in `../data/`.
Each module of `dfm_figures/` contains one figure: the presentation settings are grouped at the top
(figure size, fonts, line widths, colors, grid, axis limits, legend placement), followed by a
`build()` function that reads the released data and returns the Matplotlib figure. `common.py` holds
the shared style, the color palette, the study constants and the data access function.

| Module | Figure | Data |
|---|---|---|
| `operating_profiles.py` | `Fig_operating_profiles` | `nominal/results_profiles.csv`, `nominal/results_B0_renewables.csv` |
| `flexibility_evolution.py` | `Fig_flexibility_evolution` | `nominal/log_nominal_DFM.csv`, `uncertainty/log_trial0_DFM.csv`, `nominal/results_nominal_summary.csv`, `monte_carlo/results_mc_trials.csv` |
| `energy_performance.py` | `Fig_energy_performance` | `nominal/log_nominal_*.csv` |
| `network_security.py` | `Fig_network_security` | `nominal/log_nominal_*.csv` |
| `monte_carlo.py` | `Fig_monte_carlo` | `monte_carlo/results_mc_trials.csv` |
| `uncertainty_reserve.py` | `Fig_uncertainty_reserve` | `uncertainty/results_reserve.csv`, `nominal/results_profiles.csv` (percentile bands redrawn from the 20,000 seeded trajectories and verified against the released reserves) |
| `ablation_sensitivity.py` | `Fig_ablation_sensitivity` | `ablation/results_ablation_summary.csv`, `sensitivity/results_sensitivity_summary.csv` |
| `flexibility_limits.py` | `Fig_flexibility_limits` (supporting) | `nominal/precompute_network_forecast.csv` |
| `degradation_model.py` | `Fig_degradation_model` (supporting) | closed-form aging model; checked against `validation/results_degradation_parameters.csv` |

Plotting conventions: quantities that are constant within a 15-min interval are drawn as step plots
(`where="post"`), and the value of the last interval is held until 24 h; no smoothing or interpolation
is applied. The schematic figures `Fig_topology3_dfm` and `Fig_dfm_framework` are author-created
artwork supplied in `../figures/` and are not generated by code.

```bash
python code/generate_figures.py --help
```

## `dfm_acdc/` — implementation of the DFM framework

| Module | Content |
|---|---|
| `config.py` | All study parameters (network limits, renewables, BESS, degradation, DFM design, uncertainty, EMS, Monte Carlo) and the input/output folders |
| `network.py` | Interface to the compiled PyDAE model of Topology-3: operating point, measurements, normalized constraint exceedances |
| `oracle.py` | Network evaluation, minimum renewable curtailment and network-deliverable BESS power (bisection) |
| `profiles.py` | Nominal 24-h trajectory: demand from the benchmark, clear-sky PV, wind, time-of-use price |
| `bess.py` | BESS plant: SOC and SOH update with the online degradation estimator |
| `degradation.py` | Xu et al. (2018) degradation model: stress functions, capacity fade, online increments, piecewise-linear segments, rainflow counting |
| `envelope.py` | Energy/health, degradation and network limits; physical and safe envelopes; active limiter |
| `uncertainty.py` | AR(1) forecast-error model and directional uncertainty reserves |
| `ems.py` | Strategy definitions (B0, B1, B2, DFM, M1-M3) and the rolling-horizon MILP |
| `simulate.py` | Closed-loop 24-h simulation and daily indicators |
| `mc.py` | Parallel execution of Monte Carlo, ablation and sensitivity runs |
| `plotstyle.py` | Plotting helpers used by the experiment notebooks |

These modules require the external Topology-3 model for any computation that involves the network
(`network.py`, `oracle.py`, `simulate.py`); see `../external/README.md`.

## `experiments/` — numerical study

Notebooks 01-11 reproduce the study in order. Their outputs are cleared; they write results to
`../output/results/` and diagnostic figures to `../output/experiment_figures/`, so that the released
data and figures are never overwritten. The diagnostic figures are working plots of each step; the
final figures of the paper are produced by `generate_figures.py`.

| Notebook | Step |
|---|---|
| `01_topology3_regression` | Inventory of the network model; regression against the original Topology-3 outputs; quasi-static check; base network operation |
| `02_profiles_and_B0` | Nominal trajectory and network operation without storage |
| `03_bess_model_validation` | BESS model verification |
| `04_degradation_model` | Degradation model implementation and verification |
| `05_flexibility_limits` | Energy, degradation and network limits; network-deliverable limits for the forecast |
| `06_uncertainty_reserve` | Forecast-error model, reserves and their out-of-sample coverage |
| `07_ems_nominal_comparison` | Rolling-horizon EMS; nominal comparison of B0, B1, B2 and DFM; realization 0 |
| `08_monte_carlo` | 100 paired realizations and paired statistical tests |
| `09_ablation` | Ablation M0-M3 |
| `10_sensitivity` | Sensitivity to `H_f`, `epsilon`, `SOH_0` and `N_ref` |
| `11_tables_export` | Tables and quoted numbers |

The Monte Carlo, ablation and sensitivity runs (2,117 closed-loop days) took about 16 h of single-process
time in total; the notebooks execute them in parallel.
